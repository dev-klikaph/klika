# KliKA.ph 💚

### Doing Good Should Feel Rewarding.

KliKA.ph is a digital impact and rewards platform that makes supporting causes more engaging and rewarding.

### Features

* Causes & Campaigns
* Points & Rewards
* Reward Redemption
* Referrals & Fundraisers
* Challenges & Leaderboards
* Donations & Payments
* Admin Management
